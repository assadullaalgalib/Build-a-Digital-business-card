# Build-a-Digital-Business-Card

A simple digital business card created using **HTML** and **CSS**.  
It shows your **photo, name, profession, location, and contact links** in a neat card layout.  

---

## 📌 Features
- Profile avatar with styled border  
- Name, title, and location  
- Contact information (LinkedIn, GitHub, Phone)  
- Responsive, mobile-friendly design  
- Clean and minimal UI
